# Sound Realms Legacy Web

[![Netlify Status](https://api.netlify.com/api/v1/badges/454468ff-0aa0-4c6b-8ae4-ea131afddb11/deploy-status)](https://app.netlify.com/sites/sound-realms/deploys)

This app serves the Sound Realms account and digital-checkout flows that have not
yet moved to Shopify. The public website and shop live at
[soundrealms.com](https://soundrealms.com).

Legacy content URLs on `web.soundrealms.com` permanently redirect to their
current Shopify equivalents.

The live version runs on Node v. 20 – this is configurable on [Netlify](https://app.netlify.com/sites/sound-realms).

## Project setup
```
npm ci
```

### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Lints files
```
npm run lint
```
